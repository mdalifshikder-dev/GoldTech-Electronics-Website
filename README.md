# GoldTech Electronics Website

Premium responsive storefront built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Run
1. Extract the ZIP.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.
3. Internet is required for Bootstrap, Google Fonts and demo photography loaded from online sources.

## Customize
- `index.html`: brand name, text, menu, section content and image URLs.
- `css/style.css`: colors and design. Edit the variables at the top under `:root` (`--gold`, `--black`, `--surface`).
- `js/app.js`: edit the `products` array to change product names, categories, descriptions, prices, labels and images.
- `assets/`: put your own local images here and reference them as `assets/your-image.jpg`.

All major sections and the CSS/JS features have explanatory comments.

## Included
Responsive Bootstrap navbar, category filters, product search, demo cart counter, newsletter demo feedback and toast notification.

## Before real launch
This is a front-end template. Cart and newsletter are demos only; no order/payment backend or email storage is connected. Add your own backend, payment provider, real contact details and store policies before launch.
